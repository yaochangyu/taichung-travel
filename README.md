## 🚇 大眾運輸核心搭乘心法

1. **高鐵往返台中市區（最強接駁）**：
   * 高鐵台中站（烏日）**室內連通**台鐵「新烏日車站」。
   * 搭乘台鐵區間車直達「台中車站」**僅需 11 分鐘**（每 10~15 分鐘一班車，單程 15 元），完全避開下班尖峰市區塞車。
2. **市區東西向黃金動脈（台灣大道公車專用道）**：
   * 往返台中車站與西區（第六市場、PARK2 草悟廣場），直接搭乘 **300～310 系列幹線公車**，班次密集如捷運，直來直往最省時。
3. **舊城短程接駁（Ubike 2.0）**：
   * 中區與東區景點距離多在 800m～1.5km 之間，騎乘 Ubike 2.0（約 5～8 分鐘）比等轉乘公車更彈性愜意。
